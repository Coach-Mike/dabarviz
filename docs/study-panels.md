# Study Panels — Design Spec

## Left Panel — Passage

- English translation (ESV or user-selectable)
- Original language (Hebrew for OT, Greek for NT) with:
  - Full pointing / accents
  - Transliteration on hover or toggle
  - Morphology on word click
- Strong’s / Lemma number
- “View in Interlinear” action

## Right Panel — Contextual Depth

### Mode 1: Connection Evidence
- Connection type (quotation, allusion, shared rare word, structural parallel, prophecy-fulfillment, thematic echo)
- Evidence score / confidence
- Supporting passages
- Manuscript notes (DSS, major codices where relevant)
- Linguistic notes
- Scholarly sources

### Mode 2: Word Study
- Lemma + Strong’s
- Root family tree (visual)
- Semantic range (with cultural usage notes)
- Every occurrence (clustered by sense)
- LXX / NT Greek connections
- Key theological uses

## Design Principles
- Dark, premium, high contrast
- Hebrew and Greek rendered in high-quality fonts (e.g., SBL Hebrew / SBL Greek)
- Smooth expand/collapse
- Never lose the visual context of the three layers
- Mobile: panels become bottom sheets
