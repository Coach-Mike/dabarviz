# DabarViz

**Visualizing the Word (Dabar) of God through its interconnected tapestry.**

Dabar (דָּבָר) is the Hebrew word for “word,” “speech,” or “thing.” In Genesis 1, God speaks and reality appears. John 1 uses the Greek *Logos* for the same reality.

DabarViz is a premium, interactive experience that lets you explore Scripture’s connections, original languages, and textual evidence in one synchronized interface:

- **Rainbow Arc** — the full canon of cross-references
- **Theme Graph** — force-directed network of core concepts
- **Biblical Globe** — places, journeys, and events
- **Original Language + Proof panels** — always contextual
